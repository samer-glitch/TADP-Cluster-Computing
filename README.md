# TADP – Trustworthy AI Data Preparation

This repository contains the implementation and experimental evaluation of the Trustworthy AI Data Preparation (TADP) framework used in our Cluster Computing study.

TADP is designed as a pre-training governance layer for centralized and federated machine learning. Before data or client contributions are used for model training, TADP evaluates their trustworthiness using a set of governance and data-quality dimensions and records the resulting decision for auditability.

The framework focuses on making data preparation more transparent, traceable, and suitable for responsible AI development.
